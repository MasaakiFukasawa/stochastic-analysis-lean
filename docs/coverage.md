# 検証範囲と記録の読み方

本文第1–13章と付録の証明、および依存する補題を `src/` に収録しています。検証対象のソースはハッシュで識別します。

検証には三つの段階があります。

1. **Leanコンパイル**：ファイルに記述した型（命題）の証明が成立するかをLeanが確認します。
2. **公理依存の検査**：対象の定理が `propext`, `Classical.choice`, `Quot.sound` 以外の公理に依存しないことを確認します。`sorry`, `admit`, 新規 `axiom`, `native_decide` による合格扱いはしません。
3. **原稿との対応確認**：原稿の仮定・計算・証明の段階が、Leanのどの命題と対応するかを人が読み取れる記録にします。これは1・2から自動的に従うものではありません。

`audit/chapters/` の `whole_chapter_verified` などは、原稿との対応確認を含む章別の検証結果です。各Lean定理には仮定が明記されています。章別の件数にはその章で使う依存補題を含み、全体の件数は重複を除いて数えます。

付録の分数ブラウン運動には、元の独立なブラウン運動から実際の伊藤積分と過程を構成する定理を収録しています。条件付き期待値、局所伊藤積分のパラメータ可測性、小質量極限、マリアバン解析の閉微分と密度、HJMモデルについても、構成と結論を結ぶ定理を追加しています。`import Book.Constructed` でこれらを読み込めます。定義・説明文・文献への案内そのものはLeanの定理ではありません。Lean定理の仮定を読むことは再利用時にも必要です。

## 再検証

直近の実行結果は [audit/latest-run.json](../audit/latest-run.json)、公開版の検証概要は [audit/release-validation.json](../audit/release-validation.json)、原稿と命題の対応は `audit/chapters/` を参照してください。
ソースのハッシュ照合、章別入口のコンパイル、公理依存の監査、新しい環境でのクリーンビルドは区別して記録しています。
全体を再ビルドして公理依存を検査するには、`python3 scripts/audit.py` を実行してください。

構成を結ぶ93モジュールと直交分解の依存モジュールを収録しています。全3,835モジュールの同時読み込みと、登録した6,777宣言の公理依存を検査済みです。既存のコンパイル済み依存ファイルを利用した検査であり、別PCでのクリーンビルドの実施を意味しません。
