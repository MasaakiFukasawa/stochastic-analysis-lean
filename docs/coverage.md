# 検証範囲と記録の読み方

本文第1–13章と付録の証明、および依存する補題を `src/` に収録しています。検証対象のソースはハッシュで識別します。

検証には三つの段階があります。

1. **Leanコンパイル**：ファイルに記述した型（命題）の証明が成立するかをLeanが確認します。
2. **公理依存の検査**：対象の定理が `propext`, `Classical.choice`, `Quot.sound` 以外の公理に依存しないことを確認します。`sorry`, `admit`, 新規 `axiom`, `native_decide` による合格扱いはしません。
3. **原稿との対応確認**：原稿の仮定・計算・証明の段階が、Leanのどの命題と対応するかを人が読み取れる記録にします。これは1・2から自動的に従うものではありません。

`audit/chapters/` の `historical_whole_chapter_verified` などは、従来の分割原稿に対する章別の検証記録です。現行v4への新たな全項目の数学的再照合が完了したことを意味しません。各Lean定理には仮定が明記されています。章別の件数にはその章で使う依存補題を含み、全体の件数は重複を除いて数えます。

付録の分数ブラウン運動には、元の独立なブラウン運動から実際の伊藤積分と過程を構成する定理を収録しています。条件付き期待値、局所伊藤積分のパラメータ可測性、小質量極限、マリアバン解析の閉微分と密度、HJMモデルについても、構成と結論を結ぶ定理を追加しています。`import Book.Constructed` でこれらを読み込めます。定義・説明文・文献への案内そのものはLeanの定理ではありません。Lean定理の仮定を読むことは再利用時にも必要です。

## 再検証

直近の実行結果は [audit/latest-run.json](../audit/latest-run.json)、公開版の検証概要は [audit/release-validation.json](../audit/release-validation.json)、原稿と命題の対応は `audit/chapters/` を参照してください。
ソースのハッシュ照合、章別入口のコンパイル、公理依存の監査、新しい環境でのクリーンビルドは区別して記録しています。
全体を再ビルドして公理依存を検査するには、`python3 scripts/audit.py` を実行してください。

構成を結ぶ93モジュールと直交分解の依存モジュールを収録しています。現在の登録対象は全3,835モジュール、6,787宣言です。直近のビルド・公理監査結果は `audit/latest-run.json` を参照してください。既存のコンパイル済み依存ファイルを利用した検査であり、別PCでのクリーンビルドの実施を意味しません。

## 現行v4の対応記録

[audit/manuscript-v4-index.json](../audit/manuscript-v4-index.json) は現行原稿の定理・補題・演習・定義などの位置、ラベル、ハッシュと、既存の証明記録を結びます。本文第1〜13章の環境、3章のC1,2補足、付録A.5を記録しました。10〜13章では、現在の定理から従来の複数の証明ブロックへたどれます。旧 `line` は分割原稿の位置で、現行の位置は `current_manuscript_locations` にあります。

定義・記法には証明を要求しません。付録A.5以外の付録には既存の証明カタログがありますが、現行の各環境への個別の結び直しは未完了として明示しています。また、証明の参照が付いたことと、全ての仮定・結論を今回あらためて数学的に照合したことは異なります。

[全体の再点検記録](../audit/whole-library-review.json)には、内部・自動生成の証明も含む11,790定理定数の追加公理検査を記録しています。標準の6,787登録宣言の監査とは数える対象が異なります。現在の原稿ファイルがこの索引と同一かは、`python3 scripts/audit.py --check-only --manuscript /path/to/asakura2e_v4.tex` で確認できます。原稿ファイル自体は公開していません。
